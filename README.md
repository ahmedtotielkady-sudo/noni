# نوني 🎙️ — تطبيق دردشة صوتية

Node.js + Express + Socket.IO + MongoDB Atlas. صوت مباشر (WebRTC) ودردشة نصية لحظية.

## المتغيرات (Environment Variables)
- `MONGODB_URI` رابط قاعدة Atlas
- `JWT_SECRET` نص عشوائي طويل
- `OWNER_USERNAME` اسم المستخدم الذي سيصبح مالك التطبيق

## التشغيل على Faable
1. ارفع الملفات على مستودع GitHub (الفرع main).
2. اربط المستودع في Faable وضع المتغيرات الثلاثة.
3. بعد النشر افتح الرابط **وسجّل حساب بنفس اسم OWNER_USERNAME أولًا** — يصبح حسابك المالك.

## كيف يعمل الشحن والوكلاء
- المالك: يولّد أكواد شحن، أو يمنح/يخصم عملات لأي مستخدم، أو يعيّن وكيلًا ويشحن رصيده.
- الوكيل (مفعّل): يحوّل من رصيده لأي مستخدم. المالك يوقف/يفعّل الوكيل متى شاء.
- المستخدم: يدخل الكود في المحفظة.
العملات افتراضية داخل التطبيق فقط (لا دفع حقيقي).
